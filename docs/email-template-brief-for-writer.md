# Задание для Writer: HTML-шаблон еженедельного письма music98.news

> Передаётся от Buffy (код-агент). Buffy делает всю техническую часть: API, отправку, подстановку данных, cron. Writer делает ТОЛЬКО дизайн/вёрстку шаблона. Готовый файл кладёт в `site/docs/email-template.html`.

## Что за письмо

**«music98.news Weekly»** — 1 письмо в неделю, визуальный дайджест:
1. **Топ-10 чарта** — позиции с движением (▲ вверх / ▼ вниз / — без изменений), обложки треков, названия + артисты
2. **2 новости** — обложка (16:9), категория-тег, заголовок, тизер 1–2 предложения, кнопка «Read more»
3. **1 релиз** — квадратная обложка, тип (Album/Single), артист — название, выжимка 1–2 предложения, кнопка «Listen on Apple Music»

Футер: логотип, слоган сайта, ссылки на соцсети (заглушки), unsubscribe-ссылка `{{unsubscribe_url}}` (обязательна), адрес отправителя.

## Жёсткие технические правила email-вёрстки

- **Таблицы, не flexbox/grid** — email-клиенты (особенно Gmail, Outlook) вырезают современный CSS
- **Все стили инлайн** (`style="..."` на каждом элементе) — `<style>` Gmail вырезает
- **Ширина письма 600px**, центрирование через `<table align="center">`
- **Картинки** — только абсолютные URL `https://music98.news/photos/...`, всегда с `alt` и фиксированной шириной в атрибутах
- **Кнопки** — только на `<a>` с padding и background (не `<button>`)
- **Тёмный текст на светлом фоне**, фирменные цвета: чёрный `#15181a`, серый `#5c6a70`, фон `#f4f6f7`, акцент можно точечно `#00fdfb` (линии, бейджи позиций)
- **Шрифты**: системная связка `-apple-system, 'Segoe UI', Arial, sans-serif` (кастомные шрифты в письмах не работают)
- **Мобильная адаптивность**: до 480px — одна колонка, картинки на 100% ширины (через `width="100%"` атрибут + `style="max-width:..."`)
- Плейеры (Apple/YouTube/Spotify) в письма **не вставлять** — они не работают в почте, только ссылки-кнопки

## Данные (плейсхолдеры — движок подставит сам)

| Плейсхолдер | Что подставится |
|---|---|
| `{{#chart}}...{{/chart}}` | цикл топ-10: `{{pos}}` `{{delta}}` `{{title}}` `{{artist}}` `{{art}}` `{{url}}` |
| `{{#news}}...{{/news}}` | 2 новости: `{{tag}}` `{{title}}` `{{excerpt}}` `{{cover}}` `{{url}}` |
| `{{release}}` блок | `{{rtype}}` `{{artist}}` `{{title}}` `{{excerpt}}` `{{cover}}` `{{url}}` |
| `{{week_label}}` | например «September 15 – 21, 2026» |
| `{{unsubscribe_url}}` | ссылка отписки |
| `{{site_url}}` | https://music98.news |

Формат — простой mustache-подобный (двойные фигурные скобки), циклы секциями `{{#имя}}...{{/имя}}`.

## Референсы стиля сайта

Логотип: `https://music98.news/logo.png` (круглый, 40px). Стиль сайта: белый фон, чёрный текст, светло-серые карточки с тонкой рамкой и радиусом 12–14px, пилюли-кнопки. В письме — то же самое, только табличной вёрсткой.

## Сдача

Один файл `site/docs/email-template.html` — цельный самодостаточный HTML (от `<html>` до `</html>`), без внешних скриптов и стилей. Buffy встроит его в движок отправки и подключит preview в админке.

Тестовые данные для проверки вёрстки: 10 любых треков (можно выдуманные), 2 новости с картинками-заглушками picsum.photos, 1 релиз. Проверить отображение в Gmail (веб), на мобильной ширине 375px и в тёмной теме Outlook — скриншоты приложить в отчёт владельцу.
