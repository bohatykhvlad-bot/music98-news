# Задание для Writer: дизайн письма music98.news (v2 — поверх готовой вёрстки)

> От Buffy (код-агент). **Вёрстка уже готова и работает** — файл `site/docs/email-template.html`.
> Твоя задача — **дизайн поверх готовой вёрстки**: цвета, типографика, декор.
> Данные подставит движок Buffy. Структуру и плейсхолдеры не трогать.

---

## 0. Главное правило

Файл `email-template.html` — **эталон структуры**. Он построен на таблицах и инлайн-стилях,
потому что Gmail/Outlook вырезают современный CSS. Это не «плохой код», это единственный
способ, чтобы письмо выглядело одинаково у 95% получателей.

**Ты editing only то, что разрешено в разделе «Зоны творчества». Всё остальное — не трогать.**

---

## 1. Что НЕЛЬЗЯ менять (жёстко)

1. **Структуру таблиц** — не добавлять/удалять `<table>`, `<tr>`, `<td>`, не менять `role="presentation"`, `width`, `cellpadding`
2. **Плейсхолдеры** `{{...}}` — ни один: `{{pos}}`, `{{delta_badge}}`, `{{title}}`, `{{artist}}`, `{{art}}`, `{{url}}`, `{{cover}}`, `{{tag}}`, `{{excerpt}}`, `{{rtype}}`, `{{week_label}}`, `{{logo_url}}`, `{{chart_url}}`, `{{site_url}}`, `{{unsubscribe_url}}`, и циклы `{{#chart}}...{{/chart}}`, `{{#news}}...{{/news}}`
3. **Никаких** `<style>`-блоков, flexbox, grid, `position:`, `float:`, `background-image`, SVG, JavaScript, веб-шрифтов (`@font-face`, Google Fonts)
4. **Никаких** `<button>`, видео, аудио-плееров, iframe — в письмах они мертвы
5. **Картинки** — только существующие URL-плейсхолдеры, атрибуты `width/height/alt` не убирать
6. **Unsubscribe-блок** в футере — не трогать вообще (юридическое требование)
7. Ширину контейнера 600px не менять

## 2. Зоны творчества (можно и нужно менять)

1. **Цвета** — текущая палитра скелета нейтральная: фон письма `#eef1f2`, карточка `#ffffff`, тёмный акцент `#15181a`, серый текст `#5c6a70`/`#9aa6ab`, фирменный циан `#00fdfb` (точечно). Можешь предложить свою палитру в этих же ролях: светлый фон + светлая карточка + тёмная шапка. Тёмную тему письма НЕ делать — только светлая.
2. **Типографика** — семейство держим `-apple-system,'Segoe UI',Arial,sans-serif`, но можешь менять размеры/веса/letter-spacing/регистр заголовков секций («The Chart · Top 10», «News», «Release of the week»)
3. **Декоративные детали** — разделители, бейджи, радиусы (8–14px), паддинги в пределах ±8px от текущих, hover-цвета ссылок
4. **Бейдж движения в чарте** `{{delta_badge}}` — сейчас нейтрально-серый. Можешь сделать цветовое кодирование: вверх — зелёный/циановый, вниз — красный, ровно — серый. ВАЖНО: бейдж один и тот же HTML для всех строк, красить надо через нейтральный фон + текст (движок подставит только текст ▲2/▼1/—), поэтому ЛИБО оставь нейтральный, ЛИБО предложи вариант с двумя готовыми бейджами в строке и объясни — я подставлю нужный классами на бэкенде. Проще: оставь один нейтральный бейдж.
5. **Preheader** (первая строка после `<body>`, невидимая) — впиши цепляющую фразу недели, до ~90 символов
6. **Логотип/шапка** — можешь предложить вариацию (светлая шапка вместо тёмной и т.п.)

## 3. Секции письма (уже работают — наполняются движком)

| Секция | Данные | Что делает движок |
|---|---|---|
| Шапка | логотип, `{{week_label}}` | URL лого, дата недели |
| Топ-10 чарта | цикл `{{#chart}}` | позиции 1–10, обложка 44px, трек/артист, бейдж движения ▲▼— |
| 2 новости | цикл `{{#news}}` | обложка 16:9, тег, заголовок, тизер, ссылка |
| 1 релиз | блок | квадратная обложка 132px, тип, артист — название, выжимка, кнопка Apple Music |
| Футер | сайт, соцсети, `{{unsubscribe_url}}` | ссылка отписки на каждого получателя |

## 4. Как проверять свою работу (обязательно)

1. Открой файл в браузере — должно выглядеть цельно на 600px и на 375px (карточки сжимаются, картинки не ломаются)
2. Прогони через https://www.caniemail.com/ каждое нестандартное CSS-свойство, которое добавил
3. Проверь, что все `{{...}}` целы: поиск по файлу `{{` должен находить ровно те же плейсхолдеры, что были
4. Скриншоты: десктоп 1280px и мобильный 375px — приложи к отчёту
